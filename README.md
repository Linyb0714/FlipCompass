# 我看看 · Glance（工程名 FlipCompass）· iOS 原生 App

> 品牌名「我看看 / Glance」（原名「罗盘 FlipCompass」已更名定稿）；代码工程、bundle id 保持 `FlipCompass` / `app.flipcompass` 不变。

**一句话概念**：以手机四方向翻转为入口的模块化 App——翻转即指向模块，进入后用手势滑动进行上下、前后的目录选择；二级模块由自建市场分发、界面由 YAML 读取配置驱动。

## 核心概念速查（需求 v1.0 已确认）

- **四向翻转导航**：竖正=温情打卡 / 竖倒=今天的想法 / 左横=生活情报站 / 右横=益智小游戏
- **方位入场（V0.2.1）**：一级模块从各自方位滑入渐显+轻回弹（M1自上/M2自下/M3自左/M4自右，待机→模块与模块直切同用），叠加单字飞行进退闭环与幽灵轨迹
- **交互三更新（V0.2.2）**：待机底部提示词 3.6s 翻牌轮播（非待机暂停）；双击空白返回上一级（一级→待机、二级→所属一级，仅真正空白触发，内容/交互元素已排除）；一、二级滑动改为自然跟手方向（下滑选下一条、左滑下一组）
- **轨迹环解压交互（V0.2.4）**：按下位定位模式互斥——按住轨迹环（环带 65~125）→ 轨迹环+刻度环双层跟手滚动（激活样式：环加深/光晕/游标浮动，每 15° 涟漪 tick，松手停位保持）；其他区域 → 指针球拖尾+颜色预示（原交互），不带动环；导航 = 色卡点按/中心与环外四向滑。另：待机时间组去位置动画（静态不闪动，V0.2.3）
- **一二级焦点系统（V0.3.0~0.3.2）**：.focus-card 浮动焦点卡——选中 = 卡滑移跟随；按住拖动为吸附式跟手（半格吸附 + 松手所见即所得）；单点 = 选择，点空白/已选中正文 = 确认，进入二级 = 「›」区/Enter；条目 324 宽，选中不位移缩放；选中条目左侧 accent bar；聚焦光晕短下偏不裁边；分组隔离（缩进在 page 内 padding，相邻 tab 元素零露出，静止态两侧干净）
- **一二级浏览体验（V0.3.4~0.3.7）**：横向容器边界接力（M1 日历条/M3 chips 优先内部滚动，顶界外拖 56 design px 切组）；accent bar scaleY 生长动画；全量 3D 液态玻璃卡片（三层阴影+内高光，按压零位移）；头部统计胶囊「色点+标签+大数值」；Toast 独立深色磨砂风（铸墨底+模块色发光圆点徽标，与白玻璃体系一眼区分）；无焦点页不再提示、上下轻碰撞反馈
- **分组边界反馈（V0.3.8~0.3.9）**：左右滑到头/尾不再 toast——模块屏橡皮筋碰撞回弹（±18px 过冲弹回，.46s 弹簧）+ 头尾边缘竖排水印「没有更多的模块了」随屏位移淡入淡出；有焦点页连击保护——3s 内到头/尾 3 次 → 弹「歇一歇」+ 锁定上下导航 2s（左右/进入/返回不受影响，成功移动即清零）
- **新建打卡项焦点化（V0.3.10 ①）**：「＋新建打卡项」纳入焦点系统——上下滑/键盘/拖动均可选中（焦点卡精确框住）；单点 = 选择，已选中再点/Enter = 确认新建；选中态虚线转模块色
- **单行卡高度品牌 token（V0.3.10 ②·M1 先行）**：设计 token `--h-row:63px`（9×7，基准 = 新建打卡项实测）；根除 .tk-go 热区撑高臃肿（负 margin 扩热区，热区不减）；四模块统一见设计待办
- **右侧动作对齐（V0.3.11）**：.tk-go 推右 = margin-left:auto 标准flex（负 margin 热区与 auto 推右共存）；受益五处：M1 task ›/编辑 ›、M2 compose ›、M3 pref ›、M4 hero ›
- **右侧缩略预览联动（V0.4.0）**：选中可进二级条目 → 模块屏右侧浮出二级页迷你骨架卡（液态玻璃）+ 贝塞尔虚线曲线从条目右缘连到缩略卡；点卡放大覆盖/再点收起；页点切换多子页（MINI 数据驱动，四模块同构）；明确动作目标（编辑表单）不显示，全局单例（切模块收起）
- **M1 全链路闭环（V0.4.1·数据驱动）**：M1.items 表驱动清单/管理/统计/热力/待机提醒；打卡 = 选中项点 ✓（成功 toast+连续天数+全联动）；详情页 = 时间+本月月历分布（橙打/红环漏/今日描边）+心情时间线；编辑/新建 = item 生长打开表单（标题/描述/提醒时间，「编辑 ›」一点直达，空标题拦截）；删除 = iOS 规则（− 钮→行右移露删除钮→确认/点其他收起）；首页遗漏提醒动态（N 项待完成·下次提醒时间，全部完成切换祝贺语）
- **M3 二级页闭环（V0.4.2·数据驱动）**：M3.items 数据表驱动（1 券 + 5 情报，替代静态 HTML）；**d4 券详情 = 状态机**（未领→已领→已用/过期四态，CTA 随状态切换 + 券码出示 + 门店列表）；**d5 情报详情** = 来源行 + 标签 + 段落正文 + 底部收藏开关（收藏实时联动 p1 收藏夹）；**p1 chips 真筛选**（联动 tags 重排 + 空态）；**d7 偏好编辑** = tag-picker 多选 + slider 单选；顺带修 pref-row 统一 63px、头部胶囊实算、M3 缩略预览接入
- **二级页导航栈通用化（V0.4.2）**：二级屏判定由 `['d1','d2','d3']` 硬编码（全文件 5 处）改为 `isDetail()` 通用判定——新增二级页零改动纳入 Esc/右滑返回/翻转提示/回待机全套导航
- **M2 草稿三件套 + 想法详情（V0.4.3·数据驱动）**：M2.items 数据表驱动（6 条：3 今日 + 3 归档）；**R8 草稿三件套真实落地**——自动落盘（每字 input 即写 Draft，替代 V0.4.1 只改文案不落盘的假实现）/ 切走不打断（零弹窗静默存盘）/ 标记看得见（记录卡副标 + d2 计数 + 待机胶囊）；**d2 升级双子页**（记录一条 / 草稿箱，点草稿回填继续写、发布后出栈、空态）；**d9 想法详情**（全文 + 心情 + 编辑/删除）

### 其余核心概念

- **一级目录**：上下滑选条目（点按进入二级），前后滑切目录页分组
- **转场动效（R6）**：碰撞主基调 + icon 3D 跳跃，全层级统一；元素带入（非跳转非遮罩）：待机→模块（icon/主题色水滴晕染）、一级→二级（选中卡片生长）、返回原路收回
- **导航状态机（R7）**：L0 待机 → L1 目录（翻转直切碰撞）→ L2 多级页面栈；L2 内翻转轻提示确认；平放收拢回待机；游戏运行态自动挂起导航
- **翻转判定（R8）**：四态模型（动作识别→减速→自适应停留）+过程预反馈 + 真机调试日志驱动参数优化
- **草稿策略（R8）**：自动落盘永不丢 + 切走不打断 + 标记看得见；永久保留
- **技术选型（T1~T3 已闭环）**：Intel MBP + Xcode 15 + iOS 17 SDK，真机 iPhone 14 Pro Max；受控系统旋转；@Observable 架构；单 target 分层 + SPM 兼容性约束；唯三方依赖 Yams；YAML DSL 四段式 + 4 布局/14 基础组件 + 预留网络字段；SwiftData 14 实体 + Provider 层；MotionLog 录制回放测试体系
- **二级模块**：来自自建「市场」（模块商店），一期内置基础模块，二三期完善市场生态
- **YAML 驱动**：一级受限模板 + 二级全 YAML（界面+动效+受限逻辑），一期内置+预留远程接口
- **技术边界**：iOS 17+，SwiftUI，CoreMotion 自研四朝向判定，SwiftData 纯本地，一期内测自用
