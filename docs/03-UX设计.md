## 二、设计约束登记（来自用户偏好与已确认需求）

**必须遵守**：

- 浅色统一（底色浅色，深色主题后续再议）
- 3D 立体感：紧凑布局、细腻微动画（卡片滚动 / 3D tilt / 光晕跟随）；**不要倒影**
- 状态色：成功绿 #22c55e / 异常红 #f5222d
- 尺度偏好：7px 基本单元（7/14/21/28 倍数体系）
- 经典 Apple 设计气质（原生、克制、精致）
- 待机屏越简洁越好（时间日期 + 罗盘四向指示 + 轻提醒）
- 转场：碰撞主基调 + icon 3D 跳跃 + 水滴晕染品牌语言；全层级统一（R6）
- 四模块各有主题色，水滴晕染色取自模块主题色（R6/T2）

**本 App 独有世界**（设计语言的取材地）：

- 罗盘：零位、指北、四向探索
- 水滴：跳入（碰撞）→ 落点晕染开（模块入场）
- 温情家庭日常：拥抱、精言、烟火气情报、把玩小游戏
- 由浅入深的把玩感

**V0.3.0 修订（用户提出四项，一、二级模块焦点系统重构）**：

- **① 跟随式焦点（.focus-card 浮动焦点卡）**：每模块一枚注入 pager-clip；选中变化由「条目类的显示/隐藏」改为**焦点卡平滑滑移跟随**（.34s 弹簧 transform 位移 + 宽高 morph）；左右切分组后焦点卡**自动迁移到新分组选中条目**；进入模块/直切/返回一级时轻弹 pulse（独立 `scale` 属性，不占 transform）。
- **② 单点语义**：单击条目 =**选择该节点**；进入二级 = 点已选中条目右侧「**›**」进入区 / 键盘 Enter。

**V0.3.1 修复（用户实测反馈三项，全局约束适用四模块）**：

**V0.3.2 修复（用户反馈，全局约束）——分组隔离**：

- 根因：`.pager-clip` 的 `padding:0 12px` **不参与 overflow 裁剪**（裁剪发生在 padding edge）——切到任一 tab 后静止态，相邻分组（page）的条目卡片会伸进左右 12px padding 带，露出一条边，即用户看到的「当前 tab 有左右模块元素」。
- 修复：缩进从 clip 移入 `.page` 内部 padding（`10px 12px 14px`）——相邻 page 露出的只是自身空白 padding，元素全部被裁剪；条目宽仍 324、mod-head 对齐不变；焦点卡换算链（clipPadL↔page 内差值）自动互补，**JS 零改动**；滑动过渡期间仍自然预览相邻分组（跟手反馈保留）。

**V0.3.2 验证**：隔离断言四模块全分组 11 组**零泄漏**（相邻 page 的 .item/.stat/.chips/.badge-grid 等与 clip 可视区零相交）✓；布局回归（324/x=12/焦点卡差值 0）✓；控制台零错误 ✓

**V0.3.8 修订（用户反馈）——分组边界碰撞回弹 + 边缘竖排水印**：

- 左右滑到头/尾无分组可切时，**不再弹 toast**——改「橡皮筋」体感反馈：模块屏整体沿滑动方向滑移过冲再弹回（`bump-l/bump-r` → `modBumpL/R` keyframes：34% 处 ±18px 过冲，.46s 弹簧曲线）。`pageStep()` 超界分支统一改调 `modBump(mod,dir)`，键盘方向键与手势两路径全覆盖；防重入（bump 类在身时忽略连击）；动画挂在 module 屏 transform 上，与 pager 平移/方位入场（in-*）短时序不冲突。
