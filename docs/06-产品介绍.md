# 我看看（Glance）· 产品介绍

> 随手记一笔 · 抬头看一眼，生活碎片都收在这。

## 一句话

「我看看」是家庭日常的小角落——把打卡、想法、情报、游戏四个面向随手收进一个 App，待机盘四向一翻，就到想看的那个角落。

## 四个模块

### 温情打卡
抱抱宝宝、拥抱爱人、给爸妈打个电话……每天的小动作打个卡。本月分布月历（橙点 = 已打、红环 = 遗漏、今天描边）和心情时间线，帮你看顾家人的温度。支持提醒时间、条目管理、打卡后状态变绿。

### 今天的想法
一两句话，就够了。写下今天的念头，写一半也自动存草稿；草稿箱随时续写，发布后出栈。月视图按日分组回翻，哪天翻回来都是生活的注脚。

### 生活情报站
- **券管理**：美团/抖音券面截图一秒导入（Vision 本机识别，图片不上传）、快捷指令/Siri 随手存券、四态流转（未领 → 已领 → 已用 / 过期）、券码复制到店核销
- **想要的推荐**：RSS/Atom 公开源订阅，拉取的情报混进今日推送
- **附近好店**：高德周边搜索，逛到哪收到哪，一键收进情报
- **收藏与偏好**：标签筛选、口味/价格偏好影响推荐排序

### 益智小游戏
每天来一局，连胜、星级与勋章陪着你坚持。战绩实算，随时翻看。

## 特色

- **待机罗盘**：四向翻转进入四个模块，一转就到
- **卡片生长转场**：点开的卡片「长」成二级页，原路收回
- **右侧缩略预览**：选中条目时浮出迷你预览卡 + 贝塞尔虚线连接
- **隐私优先**：数据全部存放在手机本地（SwiftData）；截图识别全程本机，不上传任何服务器

## 命名与视觉

- **中文名**：我看看——它就是打开 App 的那个动作本身
- **英文名**：Glance——一瞥
- **图标**：淡白底上的一张圆角卡片，四模块主题色（橙 / 紫 / 绿 / 黄）从四角向内弥散交融——随手翻开的一页生活
